# 历史文档归档

> 状态：Archived  
> 适用范围：历史追溯，不代表当前实现，不可直接作为新的实施指令。

本目录保存曾用于设计、迁移、排障或阶段实施的资料。它们有助于理解代码为何演变为当前形态，但其中的路径、架构结论、状态行和待办事项可能已经过时。

## 内容

- `designs/`：已被实现、替代、搁置或待重新评审的设计方案。
- `plans/`：历史阶段计划、实施记录和排障计划。
- `case-studies/`：故障案例与经验复盘。

如需重启归档中的事项，应在 `docs/specs/` 新建规格，重新验证当前源码、范围、风险和验收条件；不要直接按归档计划实施。
